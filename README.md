# Dexter U.S. Chuck VST

Independent ChucK-based VST3 instrument and effect plug-ins by Dexter U.S. Includes a syntax-highlighted ChucK editor, separate instrument/effect script folders, and a Windows x64 build workflow.

See [native project build instructions](native/dexter-chuck-vst/README.md). This repository intentionally excludes the separate Chuck Racks port and does not reuse its application source.
